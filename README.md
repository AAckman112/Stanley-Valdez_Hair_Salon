A Few User Stories: • As a user, I wish to have a role that matches my needs so that I can successfully be identified as an admin, client, or hairdresser

• As a user, I wish to change my password so I can keep my account secure

• As a client, I want to be able to manage my appointments so that I can reschedule or cancel my appointments

• As an admin, I want to be able edit all stylists’ bookings/availability, prices of services, and all parts of saved information.

• As a stylist, I can create/edit my own appointments, view users’ preferences and hair types, and refer the patient to a different stylist for their needs

• As a user, I wish to log in so I must authenticate with my username/password

• As a user I want to be able to see my dashboard upon authenticating so I can view the information that’s important to my role
